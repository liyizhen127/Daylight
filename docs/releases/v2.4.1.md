# Daylight v2.4.1

Daily reflections now use the text you wrote as the Calendar event title. Multiple lines appear as one line in the title. The notes keep the original text and line breaks. The next sync updates existing linked events in place, including their original 23:00–23:15 time slot.

The Reminders picker now reads lists directly after macOS grants access and refreshes them when reopened. It includes the system default list when writable. Separate messages explain missing permission, empty results, read-only lists, and a previously selected list that has disappeared.

The Apple Silicon app requires macOS 14 or later and uses an ad-hoc signature. Download the app or source ZIP and check the file against `SHA256SUMS.txt`.

## 简体中文

每日反思会用你写的内容作为日历标题。多行内容在标题里以空格连接，备注保留原文和换行。下次同步会直接更新之前关联的日程，时间仍为当天 23:00–23:15。

修复了提醒事项已获授权却在选择清单前显示“所选提醒事项清单不可写”的问题。重新打开选择器会刷新清单，系统默认的可写清单也可选择。权限不足、没有可见清单、清单只读和已选清单失效时，设置会分别给出对应提示。
