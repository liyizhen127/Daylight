# Daylight v2.4.0

Daily goals can now sync to a chosen Apple Reminders list. Each dated reminder shows the actual and estimated number of Pomodoros. Renaming or checking off a task and completing a focus session update the linked reminder. On macOS 15 or later, enable Scheduled Reminders in Calendar to see the goals alongside events.

A separate option sends daily reflections to a chosen calendar at 23:00 local time. Each entry occupies 23:00–23:15 on the reflection date. Later edits update the same event. Daylight catches up when the Mac wakes or the app reopens. Select a planner date and click the sync button to sync that day immediately.

Open settings with Command-comma, select each destination, and enable the channels you want. Existing data stays in schema 3. All 51 tests passed, including tests with a simulated Apple store for retries, duplicates, timing, permission denial, edits and deletion.

The arm64 build supports macOS 14 or later and uses ad-hoc signing. Download the app or source ZIP and verify it with SHA256SUMS.txt.

## 简体中文

在「每日计划同步」选择清单和日历后，日目标会自动生成带日期的提醒事项，包含实际和预估番茄数。每日反思在 23:00 写入对应日期的日历日程。休眠或退出后会在下次运行时补同步。在每日计划选中日期后，点击「同步这一天」可手动补写或更新。
