# Daylight v2.2.0

## English

### Overtime and session reviews

- Reaching a focus deadline now opens a movable, non-modal window and continues counting overtime instead of starting a break automatically.
- Click Start Break to finalize one Pomodoro, begin a full break, and rate the session as great, okay, or poor. Add an optional reflection while the break runs.
- The menu bar shows overtime as `+MM:SS`. The window appears once per session and does not reclaim focus on every tick.
- Ratings and reflection drafts autosave, survive relaunch, and can be reopened from recent focus history.
- Calendar events use the actual end time, including overtime. Private review text and ratings remain local.

### Upgrade and compatibility

The app remains in Simplified Chinese. This release supports Apple Silicon Macs running macOS 14 or later and uses ad-hoc signing; it is not Apple-notarized.

Data upgrades to schema 3 with an immutable `planner.before-v3.json` backup. Existing goals, sessions, settings, and timers are preserved. Versions 2.1 and earlier cannot read schema 3; rolling back also requires restoring the pre-upgrade data backup.

40 automated tests passed, including overtime, persistence, Calendar, window presentation, and Chinese input-method regression tests. No test events were sent to a real calendar.

### Assets

- `Daylight-v2.2.0-macOS-arm64.zip`: ready-to-run application.
- `Daylight-v2.2.0-source.zip`: source code, tests, and bilingual documentation.
- `SHA256SUMS.txt`: archive checksums; verify with `shasum -a 256 -c SHA256SUMS.txt`.

## 简体中文

### 额外专注与番茄评价

- 到达预设时长后自动弹出可拖动窗口，继续显示额外专注的分、秒，不再自动休息。
- 点击“开始休息”后结算同一颗番茄，立即开始完整休息，并选择“很好／一般／差劲”、填写感受。
- 状态栏同步显示 `+分:秒`；窗口不会随每秒刷新重新抢焦点。
- 评价与感受草稿自动保存，重启后保留，可从最近专注记录再次查看、修改。
- 日历记录包含额外专注的实际时长，评价和感受仅保存在本机。

应用内仍保持中文，支持 macOS 14+ 的 M 系列 Mac；采用本地签名，尚未经过 Apple 公证。

首次打开会升级为数据格式 3，并自动保留 `planner.before-v3.json`。原有目标、记录、设置和计时继续使用。2.1 及更早版本不能读取新格式；如需回退，请同时恢复升级前备份。

40 项测试通过；界面测试使用隔离数据，未向真实日历写入测试事件。
