# Daylight v2.1.1

**A native macOS menu bar planner and Pomodoro timer.**

## English

The app is named **Daylight**. Its interface remains in **Simplified Chinese**; the README is available in English and Chinese.

### Included

- Long-term, monthly, weekly, and daily checklists with retained completed items.
- Daily reflection, task-based Pomodoro timers, estimates, and completed-session counts.
- Configurable short and long breaks, menu bar controls, and remaining-time display.
- A monthly tomato harvest with gravity, collisions, stacking, and click-to-bounce.
- Optional Apple Calendar sync for completed and interrupted focus sessions.
- Local autosave, JSON backup and restore, Markdown export, and Chinese input-method support.

### Requirements and installation

- macOS 14 or later on an Apple Silicon Mac (M series). This binary does not support Intel Macs.
- Unzip the application archive and drag `Daylight.app` into Applications. Open it and use its menu bar tomato icon.
- The build uses local ad-hoc signing and **has not been notarized by Apple**. It is not a Developer ID-signed distribution, so macOS may block first launch pending user approval.
- Calendar access is optional and requested only when you enable Calendar sync.

Upgrading keeps the existing bundle identifier and data directory (`~/Library/Application Support/DaylightGoals/`). Quit the old app before replacing it. Renaming the app does not translate or reset existing goals and records.

## 简体中文

应用名称为 **Daylight**，内部界面仍保持**简体中文**，README 提供中英两个版本。

### 主要功能

- 长期、月、周、日四级目标清单，完成后划线保留。
- 每日反思、任务专属番茄钟、预估与实际完成番茄数。
- 可调节的普通休息与长休息，状态栏任务选择和剩余时间显示。
- 本月番茄收获区，支持重力下落、碰撞、堆叠与点击弹跳。
- 可选将完成或中断的专注时段同步至苹果日历。
- 本地自动保存、JSON 备份与恢复、Markdown 导出，以及中文输入法组词保护。

### 下载与安装

- 普通使用者下载 `Daylight-v2.1.1-macOS-arm64.zip`；源码为 `Daylight-v2.1.1-source.zip`。
- 需要 **macOS 14 或更新版本、Apple Silicon（M 系列）Mac**。此二进制包不支持 Intel Mac。
- 解压后将 `Daylight.app` 拖入“应用程序”，打开后点击状态栏番茄图标使用。
- 当前使用本地 ad-hoc 签名，**尚未经过 Apple 公证**，也未使用 Developer ID 签名；首次打开时，macOS 可能阻止运行并要求用户确认。
- 日历同步默认关闭，需要时再开启并授权。

升级前请退出旧版本。应用标识和数据目录保持不变，已有目标、反思和番茄记录继续使用；更名不会翻译或清空个人内容。

该版本已通过 35 项测试和 Release 构建检查。公开应用包已移除调试与本地符号，未检测到开发者主目录路径，并通过签名校验。压缩包不包含个人记录、测试运行数据、凭据或构建日志。尚未在所有声明支持的 macOS 版本上实机验证。

可在下载目录运行 `shasum -a 256 -c SHA256SUMS.txt` 校验两个压缩包。
