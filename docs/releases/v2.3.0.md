# Daylight v2.3.0

## English

### Menu bar cultivation companion

- Add a golden, seated cultivator to the left of the timer badge and idle tomato count.
- During focus and overtime, bright energy streaks converge into the figure through an anime-inspired flame aura, rotating halo arcs, and expanding pressure waves.
- Short breaks, long breaks, and idle time show a motionless pose. The system Reduce Motion setting also keeps the artwork still.
- The small animation view runs separately from timer/model updates and does not intercept menu bar clicks.
- Original vector artwork adapts to light and dark appearances, with no downloaded assets, extra permissions, or changes to stored data.

43 automated tests passed. The application interface remains in Simplified Chinese.

### Download

- `Daylight-v2.3.0-macOS-arm64.zip`: application for Apple Silicon Macs running macOS 14 or later.
- `Daylight-v2.3.0-source.zip`: source, tests, and bilingual documentation.
- `SHA256SUMS.txt`: checksums; verify with `shasum -a 256 -c SHA256SUMS.txt`.

The app uses ad-hoc signing and is not Apple-notarized. Existing schema 3 records are preserved; no data migration is needed from version 2.2.
