# Daylight v2.3.1

## English

### Daily long-break cadence

Long breaks now depend on completed Pomodoros within the same local calendar day. With the default interval of 4, today's 4th, 8th, and 12th completions trigger a long break. Three completions yesterday plus one today now starts a short break.

- Completion history determines the daily count, so relaunches and counters saved by older versions cannot carry yesterday's progress forward.
- Focus that crosses midnight counts on the date you click Start Break, including overtime. The original task association is preserved.
- Early interruptions do not count. An already-running break keeps its scheduled end across midnight.
- The interval remains configurable; Chinese settings now explicitly describe the daily rule.

46 automated tests passed, including new regression tests for consecutive days, midnight overtime, relaunch, stale counters, and interruptions. Existing schema 3 data, goals, reviews, calendar settings, and active timers are preserved; no migration is required.

## 简体中文

### 长休息按天计算

默认当天完成第 4、8、12…颗番茄时才触发长休息；昨天完成 3 颗、今天完成 1 颗，只会进入普通休息。

- 根据当天已保存的完成记录统计，重启不会丢失当天进度，旧版本的累计计数不会带入下一天。
- 跨午夜专注按点击“开始休息”的日期计算，包含额外专注时间，仍保留原任务归属。
- 提前中断不计数；已开始的休息跨过午夜后继续按原定时长运行。
- 长休息间隔仍可调整，设置界面已明确标注“当天每完成”。

46 项自动化测试通过。原有数据、目标、评价、日历设置和计时均保留，无需迁移数据。支持 macOS 14+ 的 M 系列 Mac，采用本地签名，尚未经过 Apple 公证。
